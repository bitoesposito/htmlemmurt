# htmlemmurt per VS Code

Supporto ai file `.emmurt` ([htmlemmurt](https://github.com/bitoesposito/htmlemmurt), HTML in napoletano):

- colori, con FratmScript dint'ê `<fratm>` e dint'ê `quanno-*` (installa pure l'estensione FratmScript; senza, se colora comme JavaScript) e CSS dint'ê `<cess>`;
- errori del compilatore mentre scrivi, in napoletano, cu 'o suggerimento;
- completamento di tag, attributi, eventi e valori (`tipo="` → `segreto`, `spunta`…);
- passando col mouse su un nome vedi l'HTML che diventa;
- snippet: `cristian`, `fratm`, `fratmda`, `chiamm`, `citofono`, `list`, `modulo`.

Per spegnere gli errori: `"htmlemmurt.diagnostics": false`.
